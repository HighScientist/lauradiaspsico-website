# Laura Dias — Psicóloga · Repositório do Projeto

Landing page estática para a psicóloga Laura de Oliveira Dias (CRP 04/73471), desenvolvida para apresentar seus serviços de psicoterapia online via TCC para adultos e idosos.

## Estrutura

- **`frontend/`** — todo o código do site (HTML, CSS, JS, imagens otimizadas). É esta pasta que deve ser publicada.
- **`context/`** — fontes originais: imagens em alta resolução e demais materiais de referência usados durante o desenvolvimento. **Não deve ser publicada** junto com o site.
- **`docs/superpowers/specs/`** — especificação técnica e de design do projeto.
- **`scripts/`** — utilitários Python para otimização de imagens.

## Documentação

## Início rápido

```bash
cd frontend && python3 -m http.server 8000
```

Acesse `http://localhost:8000` no navegador.
